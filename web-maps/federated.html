Federated STA Data - Leaflet Map Example

A Leaflet map connected to multiple federated OGC SensorThings API endpoints as part of the NERC EDS Amplify project, including:

  • https://linkedsystems.uk/sensorthings/v1.1
  • https://sensors.bgs.ac.uk/FROST-Server/v1.1

SensorThings API is an international standard developed by the OGC using a RESTful OData interface. Users can connect to the API using Python, Jupyter Notebooks, QGIS, Esri, and web map clients.
